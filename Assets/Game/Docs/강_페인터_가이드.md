# 강/물길 페인터 사용 가이드 (River Painter)

세계지도 위에 **2D로 강·운하·해협을 그려서** 배가 지나갈 물길을 만드는 도구입니다.
3D 화면에서 그릴 때 생기던 "시점·높이에 따라 위치가 어긋나는" 문제가 없습니다 (2D 캔버스라 항상 정확).

- 도구: 메뉴 **`Game ▸ River Painter`** (창으로 열림, Empty Object·Play 불필요)
- 결과물: `Assets/Game/Data/MapSubtracts/` 안에 `MapSubtractData` 에셋
- 반영: 그린 뒤 **`Game ▸ Bake World Land Mesh from GeoJSON`** 실행

---

## 빠른 시작 (5단계)

1. 메뉴 **`Game ▸ River Painter`** → 세계지도가 있는 창이 열림
2. 모드를 **Draw** 로 두고, 지도 위를 **좌클릭**해 강이 흐를 길을 따라 점을 찍기 (2개 이상)
3. 상단에서 **Kind / Width(km) / 이름** 설정
4. **● Save River** 클릭 → 강 데이터 저장
5. **`Game ▸ Bake World Land Mesh from GeoJSON`** 실행 → 지도에 반영
   - 지도 색이 풀리면 **`Game ▸ Colorize World Land by Biome`** 한 번 더

---

## 화면 구성

- **상단 툴바** — 모드, 종류, 폭, 이름, 편집 버튼들
- **가운데 지도** — 세계지도(초록=육지, 파랑=바다, 30°마다 격자선). 여기에 그림
- **하단 목록** — 저장된 강 전체 (켜기/끄기, Edit, Delete)
- 지도 위에 마우스를 올리면 좌하단에 **경도/위도** 가 실시간 표시됨

---

## 모드

### Draw (그리기)
- 지도 위 **좌클릭** = 강 경로(중심선)에 점 추가
- 점을 따라 선이 이어지며 강이 됨

### Erase (지우개)
- 상단 모드를 **Erase** 로 변경
- 지도 위 **기존 강 선을 클릭** → 그 강이 삭제됨 (확인창)

---

## 종류 (Kind)

| 종류 | 효과 | 쓰임 |
|------|------|------|
| **Sea** | 육지를 실제로 제거(진짜 물길). 콜라이더도 없어져 **배가 물리적으로 통과** | 운하·해협·바다로 이어지는 길 (추천) |
| **River** | 육지는 그대로 두고 그 영역에서만 배 통과 허용(시각적 강) | 육지 모양 유지하고 싶을 때 |
| **Land** | 없던 곳에 새 육지 추가 | 섬·땅 추가용 |

> 배가 **실제로 지나가는 물길**을 원하면 **Sea** 를 쓰세요.

---

## 폭 (Width km)

- 강의 폭(킬로미터). 슬라이더로 10~500km
- 대략 환산: **100km ≈ 13.5유닛, 200km ≈ 27유닛** (맵 가로 5400유닛 기준)
- 좁은 강: 50~100 / 보통 강: 150~250 / 넓은 해협: 300+

---

## 그리는 중 수정

- **Undo Point** — 마지막에 찍은 점 하나 취소
- **Clear** — 지금 그리던 경로 전체 지우기

## 저장된 강 관리 (하단 목록)

- **체크박스** — 강을 끄기/켜기 (삭제 않고 잠시 비활성)
- **Edit** — 그 강을 불러와 점을 수정 → **Save 하면 덮어쓰기**(새로 안 만들고 갱신)
- **Delete** — 그 강 삭제

## 기타

- **기존 표시** 토글 — 이미 만든 강들을 흐린 하늘색으로 표시 (겹치지 않게 그리기 좋음)
- **새로고침** — 지도 미리보기·목록 다시 읽기

---

## ⚠ 중요 — Bake를 꼭 다시!

강을 **추가·수정·삭제**한 뒤에는 반드시
**`Game ▸ Bake World Land Mesh from GeoJSON`** 을 다시 실행해야 지도(메쉬·콜라이더)에 반영됩니다.
페인터는 "데이터"만 만들고, 실제 지도는 Bake 때 다시 만들어지기 때문입니다.

순서: **페인터로 그리기 → Save → Bake → (색 풀리면) Colorize**

---

## 자주 묻는 것

- **그렸는데 지도에 안 보여요** → Bake를 안 했거나, 그 강이 비활성(목록 체크 해제)인지 확인
- **배가 안 지나가요** → Kind가 **Sea** 인지 확인 (River는 배 통과 로직이 따로 필요). Sea는 육지·콜라이더가 제거되어 물리적으로 통과
- **지도 미리보기가 낡았어요** → MapPreview.png 는 한 번 구운 이미지라, 베이크로 지형이 크게 바뀌면 미리보기도 다시 만들면 좋아요 (요청 시 갱신 가능)
- **위치가 살짝 어긋나요** → 미리보기 지도와 실제 베이크 지형은 같은 좌표(경도×15, 위도×15)지만, 미리보기는 단순 래스터라 해안선이 약간 다를 수 있어요. 정확히는 Bake 후 결과로 확인
