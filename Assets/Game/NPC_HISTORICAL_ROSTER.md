# NPC 100명 실존 인물 명단 (1000 ~ 1830)

[M3NpcSeeder](Scripts/Editor/M3NpcSeeder.cs) 가 생성하는 100명을 **위키피디아 등재된 실존 인물** 로 큐레이션. `Game ▸ Seed M3 NPCs` 실행 시 이 명단대로 생성됨.

**제외**: 8명의 주인공 후보 ([M2CharacterSeeder](Scripts/Editor/M2CharacterSeeder.cs)) — 엔리케 왕자 / 엘카노 / 카다모스토 / 바렌츠 / 허드슨 / 피리 레이스 / 임상옥 (이순신 대신 신규) / 정화. 이순신은 NPC 호위선 #16 으로 이동.

**스탯 보정 표기** — 강조 인물은 능력치 90+ 고정 ⭐ 표시. 나머지는 타입별 랜덤.

## 영입 효과 (전문가 보너스 — [PlayerCrew.cs](Scripts/Player/PlayerCrew.cs))

각 NPC 의 가장 높은 능력치(전공)에만 보너스 부여:
- 해적: **3~5 보너스** (저stat 도 floor 3 보장)
- 호위선·상선: 1~5 보너스

예시:
- 검은수염 영입 → 용기 +5 (전공 = 용기)
- 이순신 영입 → 용기 +5 (95 / 20 = 4 → clamp(3,5))
- 미쓰이 다카토시 영입 → 눈썰미 +4 (90/20 = 4)
- 야코프 푸거 영입 → 눈썰미 +5 (95/20 = 4 → clamp ceil)
