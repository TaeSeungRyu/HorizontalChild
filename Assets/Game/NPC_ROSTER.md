# NPC 100명 — 능력치·배 배정 현황

[M3NpcSeeder](Scripts/Editor/M3NpcSeeder.cs) 가 생성한 100명 NPC 의 현재 상태. 각 NPC 가 어떤 배를 타는지 + 능력치 + 게이트 일람.

> 자동 생성된 스냅샷. `Game ▸ Seed M3 NPCs` 재실행 후에는 이 파일을 다시 갱신해야 정확.

## 기호 안내

| 기호 | 뜻 |
|---|---|
| ⚔ → 대포 | NpcDefinition.cannonPower (ShipData.cannonPower 와 별개 — NPC 개별 튜닝) |
| 🛡 → 내구 | NpcDefinition.maxDurability |
| ⏱ → 발사 | attackInterval (초) |
| 💪 용기 / ⛵ 항해 / 👁 눈썰미 | CharacterData 능력치 (1~100) |
| 💰 영입가 | hireBasePrice (G) |
| 보너스 | 고용 시 플레이어에 합산되는 (용기/항해/눈썰미) — Vector3Int |
| 명성 | ✨ = requiredGoodReputation, ☠ = requiredBadReputation |
